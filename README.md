# CodeAlpha Data Analytics Internship

This repository contains my project submissions for the **CodeAlpha Data 
Analytics Internship**. Each task explores a different core skill in 
data analytics, using the Titanic dataset and a live website for scraping 
practice.

## 📁 Projects

### Task 1: Web Scraping
Extracted quote and author data from `quotes.toscrape.com` using 
`requests` and `BeautifulSoup`. Parsed the HTML structure, extracted 
relevant elements, and structured the results into a clean CSV dataset.

**Files:** `Task1_WebScraping.ipynb`, `quotes_dataset.csv`  
**Libraries used:** requests, BeautifulSoup, pandas

---

### Task 2: Exploratory Data Analysis (EDA)
Performed exploratory analysis on the Titanic dataset to understand 
passenger survival patterns. Investigated missing data, summary 
statistics, and survival trends across gender, passenger class, and age.

**Key findings:**
- Women survived at 74.2%, compared to 18.9% for men
- 1st class passengers survived at 63%, vs. 24% for 3rd class
- Age and Cabin columns had significant missing data

**Files:** `Task2_EDA.ipynb`  
**Libraries used:** pandas

---

### Task 3: Data Visualization
Built visualizations to represent the patterns found during EDA, 
including survival counts, gender and class comparisons, age 
distribution, and a correlation heatmap.

**Files:** `Task3_Visualization.ipynb`  
**Libraries used:** matplotlib, seaborn
